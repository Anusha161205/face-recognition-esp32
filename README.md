# 📸 Smart Attendance System using ESP32-CAM

## 🔍 Overview

This project implements a **face recognition-based smart attendance system** using ESP32-CAM. It automates attendance marking by capturing and identifying faces in real time, eliminating manual errors and proxy attendance.

---

## ❗ Problem Statement

Traditional attendance systems:

* Are time-consuming
* Prone to human errors
* Allow proxy attendance (RFID misuse)

---

## ✅ Proposed Solution

A **real-time AI-based attendance system** that:

* Captures face using ESP32-CAM
* Detects and recognizes individuals
* Automatically logs attendance

---

## 🚀 Key Features

* Real-time face detection and recognition
* Prevents proxy attendance
* Automatic attendance logging with timestamp
* Wireless video streaming via WiFi
* Secure data handling

---

## ⚙️ System Working

1. ESP32-CAM captures face images
2. Face detection is performed
3. Face recognition verifies identity
4. Attendance is logged automatically

---

## 🌐 Face Recognition Processing

* Image captured by ESP32-CAM
* Sent to external system (PC/Cloud)
* Face features extracted
* Compared with stored database
* Match → Attendance marked

---

## 🧠 Advanced Features (Conceptual)

* Liveness detection (eye blink, head movement)
* Anti-spoofing (detect fake images/videos)
* AI-based verification

---

## 🔌 Hardware Components

* ESP32-CAM
* FTDI Programmer
* Jumper wires
* Power Supply (5V)
